# 🪙 رقيم (Raqeem) — دفتر المحاسبة والمصاريف والذمم الصوتي العربي (v3)

**رقيم (Raqeem)** هو دفتر محاسبي متكامل للمصاريف الشخصية والمستحقات والذمم المشتركة، عربي أصيل، صوتي أولاً (Voice-First)، يعمل بنسبة **100% دون إنترنت (Offline-First)** مبني بأحدث تقنيات **Compose Multiplatform (CMP)** ومعايير UnSlop FinTech.

---

## ✨ المميزات المعمارية والمحاسبية

1. **دفتر محاسبي متكامل ومستحقات الذمم (`ReceivablesLedger`):**
   - **حصص الآخرين ديون مستحقة:** المبالغ المدفوعة نيابة عن الغير تسجل كمستحقات، ولا تدخل في مصاريف المستخدم الشخصية.
   - **المبلغ الفعلي:** `effectiveAmount = myShare ?: amount` لجميع الإجماليات والميزانية والتقارير.
   - **حظر الحذف الصامت:** تسوية الديون لا تُحذف بل تُلغى (`voidedAt`)، وحذف المصاريف ذات الديون يتم حذفاً ناعماً (`deletedAt`) ويبقى في سجل التدقيق المالي.
   - **الأرقام المرجعية:** رقم تسلسلي فريد (`refNo`) لكل حركة مالية، وتخصيص، وتسديد.
   - **فصل التواريخ:** تاريخ السداد الفعلي (`settledAt`) منفصل عن تاريخ التسجيل (`recordedAt`).
   - **حسابات النقود والكسور (`Money`):** حفظ بوحدات صغرى حسب منازل العملة (د.أ: 3 منازل، ₪ ور.س وج.م و$: منزلتان)، مع تقريب النصف للأعلى وتوزيع باقي القسمة لحصة المستخدم دون أي فرق في الإجمالي.

2. **تحويل صوتي محلي بالكامل (100% On-Device Whisper.cpp):**
   - محرك تفريغ صوتي أصلي مبني من المصدر عبر **CMake & Android NDK** (`libwhisper.so` لمعمارية `arm64-v8a`) باستخدام whisper.cpp كموديول فرعي (`v1.7.4`).
   - نموذج مدمج ومكمّم `ggml-tiny-q5_1.bin` (32MB) في الأصول دون أي تنزيل شبكي وقت التشغيل.
   - كاش لسياق النموذج في الذاكرة لتسريع الاستجابة المتتالية مع تحرير حتمي للموارد في `onCleared()`.
   - ضمان ظهور واجهة دائماً: أي تعثر أو صمت ينتهي فوراً بالشيت اليدوي الهادئ دون ترك المستخدم بلا واجهة.
   - حزمة Release AAB للمتجر بحجم **~35.7 MB** (أقل بكثير من سقف 200MB لـ Google Play).

3. **محلل اللهجات العربية للدفعات المتعددة والتخصيصات (`LocalDialectExpenseParser`):**
   - استخراج الدفعات المتعددة اعتماداً على المبالغ كمرتكزات («دفعت 30 بنزين و15 قهوة و100 سوبرماركت»).
   - استخراج التخصيصات والذمم («مية شيكل ثلاثين إلي وأربعين للبيت وثلاثين لأخوي»، «نصيبي ثلاثين والباقي على محمد»).
   - حماية الكميات من التفسير كمبالغ («نص كيلو جبنة بـ 15 شيكل»).
   - دعم 30+ سيناريو لهجات عربية تشمل الشامي والمصري والخليجي مع الأرقام المشرقية والكلمات المركبة.

4. **شيت المراجعة المتقدم وإرفاق الإيصالات (`ExpenseReviewSheet`):**
   - بطاقات مراجعة مستقلة لكل عنصر مستخرج في الدفعة، تتيح تعديل العنوان والمبلغ والحصة الشخصية والتصنيف.
   - قسم تقسيم الفاتورة مع خيار «سُدد الآن» وإضافة مشاركين.
   - إمكانية تعديل النص المنطوق الخام مع زر إعادة التحليل التلقائي.
   - إرفاق صور الإيصالات المحلية وتخزينها محلياً في `filesDir/receipts/`.

5. **شاشة المستحقات وإدارة الذمم (`ReceivablesScreen`):**
   - قائمة الشركاء والمدينين مع رصيد كل شخص لكل عملة.
   - تفاصيل العمليات مع حالة الدين (قيد التحصيل / مسدد جزئياً / مسدد بالكامل).
   - تسجيل تسديد جزئي أو كامل مع منتقي تاريخ، وإلغاء التسديد (void) مع إمكانية التراجع.
   - زر تسديد جماعي لكافة المستحقات المفتوحة لشخص بعد تأكيد صريح.

6. **تقارير محاسبية وتصدير احترافي (Excel 5 صفحات و PDF):**
   - كاتب XLSX نقي بـ Kotlin دون أي مكتبات خارجية: 5 أوراق عمل (الملخص، المستحقات التفصيلية، التسديدات، كشوف الحسابات، وأعمار الديون 0-7، 8-30، 31-60، >60 يوماً)، مع تجميد الترويسة وصيغ `=SUM` واتجاه RTL.
   - كشف حساب الشخص (Statement of Account) مع رصيد جارٍ مستمر وعزل الحركات الملغاة.
   - فحص المطابقة والنزاهة الرياضية (`LedgerIntegrityChecker`).
   - تسمية ملفات فريدة مانعة للتصادم (`raqeem_{type}_{scope}_{timestamp}.{ext}`) وتنظيف تلقائي لما هو أقدم من 7 أيام.
   - حدود المنصات: تصدير PDF متاح على أندرويد فقط عبر Canvas/PdfDocument، بينما تصدير Excel متاح نقياً على كافة المنصات.

7. **تخزين ذري محلي وتوافق خلفي مطلق:**
   - تخزين محلي JSON مع كتابة ذرية لملف مؤقت `.tmp` قبل الاستبدال لحماية البيانات عند انقطاع الطاقة.
   - عزل الملفات التالفة ونقلها إلى `.corrupt` بختم زمني بدلاً من مسحها.
   - توافق خلفي كامل مع المخطط القديم دون فقدان أي بيانات سابقة.
   - انعدام تام لأذونات الإنترنت (`android.permission.INTERNET`).

8. **تصميم UnSlop FinTech فائق الانضباط:**
   - لوحة ألوان دقيقة: BackgroundSlate `#0E131F`، SurfaceCard `#182032`، EmeraldGreen `#00C48C`، ElectricCyan `#22D3EE`، CoralRose `#FF5C5C`.
   - عدادات متدحرجة رأسية (`RollingNumberTicker`) بانزلاق سلس بلا ارتداد زائف.
   - رسم بياني أسبوعي تفاعلي بالسحب مع دعم كامل لاتجاه RTL وتلميح مصمت.
   - زر صوتي بلون الزمرد الموحد وقراءة السعة في مرحلة الرسم `drawBehind` لضمان 60 إطاراً في الثانية.
   - سحب للحذف فقط وقائمة ضغط مطول لمنع تعارض الإيماءات، وصفر إيموجي في كامل الواجهة.

## 🏗️ هيكلية المشروع

* `shared/`: كود Kotlin Multiplatform المشترك:
  * `commonMain/`: نماذج البيانات، محلل اللهجات `LocalDialectExpenseParser`، عقود MVI، الواجهات المشتركة (Splash, Onboarding, Dashboard, Sheets).
  * `androidMain/`: ربط محرك الصوت الخام `AudioRecord`، ومحرك `AndroidLocalSpeechTranscriber` عبر JNI، والتخزين المحلي.
  * `jvmTest/`: اختبارات وحدوية وتكاملية واختبارات التطهير وتدوير الشاشة ودورة حياة النموذج.
* `androidApp/`: تطبيق أندرويد:
  * `src/main/cpp/`: ملفات CMakeLists.txt و jni.cpp و whisper.cpp (Git submodule v1.7.4).
  * `src/main/assets/models/ggml-tiny-q5_1.bin`: نموذج GGML المكمم (31MB).
  * `proguard-rules.pro`: قواعد R8 لحفظ دوال JNI.
* `desktopApp/`: تطبيق سطح المكتب (JVM).
* `iosApp/`: تطبيق iOS.

## 🛠️ إعداد النموذج للمطورين (Model Setup)

قبل بناء التطبيق للمرة الأولى على بيئة تطوير جديدة أو CI، تأكد من تهيئة الموديول الفرعي وتنزيل ملف النموذج:

```powershell
# 1. تهيئة الـ Submodule
git submodule update --init --recursive

# 2. تنزيل نموذج whisper.cpp المكمم (31MB)
mkdir -p androidApp/src/main/assets/models
curl.exe -L -o "androidApp/src/main/assets/models/ggml-tiny-q5_1.bin" "https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-tiny-q5_1.bin"

# 3. التحقق من تطابق الـ Checksum (SHA-256)
Get-FileHash -Algorithm SHA256 "androidApp/src/main/assets/models/ggml-tiny-q5_1.bin"
# Expected Hash: 818710568DA3CA15689E31A743197B520007872FF9576237BDA97BD1B469C3D7
```

## 🚀 أوامر البناء والاختبار (Build & Verification)

### 1. تشغيل الاختبارات الشاملة:
```powershell
.\gradlew.bat :shared:jvmTest
```

### 2. بناء حزمة أندرويد التجريبية (Debug APK):
```powershell
.\gradlew.bat :androidApp:assembleDebug
```

### 3. بناء النسخة النهائية لـ Google Play (Release AAB):
```powershell
.\gradlew.bat :androidApp:bundleRelease
```
*يتم بناء مكتبة C++ الأصلية عبر CMake تلقائياً وحفظ ملف AAB النهائي في:*
`androidApp/build/outputs/bundle/release/androidApp-release.aab`
*(الحجم: **~35.3 MB** مع R8 Minification و ProGuard).*
